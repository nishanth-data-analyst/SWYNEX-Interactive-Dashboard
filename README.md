# SWYNEX – Interactive Healthcare Dashboard

## 📊 Project Overview

This project is an interactive healthcare dashboard created using **Microsoft Power BI** as part of my SWYNEX internship Task 3.

The dashboard analyzes healthcare data and presents important information about patients, hospitals, admissions, medical conditions, and billing.

## 🎯 Objectives

- Analyze healthcare patient data
- Create meaningful KPIs
- Identify important trends and patterns
- Compare hospitals and medical conditions
- Analyze admission patterns
- Understand billing information
- Present insights through an interactive dashboard

## 🛠️ Tools Used

- Microsoft Power BI
- SQL
- Microsoft Excel
- Power Query

## 📌 Dashboard Features

The dashboard includes:

- Total Patients
- Patient gender analysis
- Medical condition analysis
- Hospital-wise patient analysis
- Admission type analysis
- Monthly admission trends
- Average billing analysis
- Total billing amount
- Interactive filters and visualizations

## 💡 Key Insights

- Female patients are slightly higher than male patients.
- Asthma has the highest patient count among the selected conditions.
- Smith PLC has the highest patient count among the top hospitals shown.
- Urgent admissions have the highest share.
- October has the highest number of admissions.
- February has the lowest number of admissions.
- Diabetes has the highest average billing among the selected conditions.
- Total billing amount is approximately ₹255.17M.
